# FrameLedger · 影视制作预算与资产版权协同平台

React + Vite + TypeScript 前端，Node.js + Express + TypeScript 服务端。面向中型影视制作团队，演示预算版本、成本预测、合同里程碑、资产版本、授权窗口冲突与审批审计的协同闭环。

## 启动

```bash
npm install
npm run dev
```

前端默认 Vite 端口 5175，API 默认 `http://localhost:4104`。

## 业务能力

- 项目 / 季 / 交付日期与预算基线；计划、承诺、实际、预测成本四账合一
- 供应商合同额度、付款里程碑与付款暴露额
- 母版、预告、海报、音频、字幕等资产版本和 checksum 登记
- 地域、平台、有效期、版权标签冲突检测
- 预算 / 资产 / 交付审批队列和审计事件
- React 控制台支持项目切换、预算表、风险雷达、审批操作和版权资产视图
- **版权例外子系统**：法务就冲突发起有期限、可撤销的范围例外（地域 × 平台 × 标签 × 短日期），指定审批后只抑制匹配切片；驾驶舱、版权页与交付预检严格区分「真实无冲突（clean）」「凭已批准例外放行（exception）」「残差真实风险（blocked）」

## 版权例外模型

- 冲突引擎输出带**版本化指纹**（资产 id@版本 + 标签 + 地域 + 平台 + 日期窗口）的精确重叠维度
- 例外生命周期：`pending`（48h SLA）→ `approved`（`scheduled`/`active`）→ `expired`/`revoked`/`stale`，以及 `rejected`/`timedout`；每次生效与失效都带理由写入仅追加事件日志
- 抑制按四维切片计算：**重叠例外**可叠加拼窗；「全球」「全部平台」为通配；视界（今天 / 预检起始日）之前的残差列为历史，不计入当前风险
- **资产换版**后旧版本上的未决 / 已批准例外立即 `stale`，须对新指纹重新申请
- **重复申请**（同冲突 + 同范围 + 仍在进行）幂等返回原单
- 审批 / 撤销使用 `revision` 乐观锁，所有写操作与交付预检共用互斥锁，避免撤销与生成并发
- 重启时回放 `data/rights-exceptions.jsonl`（`EXCEPTIONS_LOG` 可改路径，`EXCEPTIONS_MEMORY=1` 用内存种子）恢复全部状态

当前使用内存数据，领域服务按模块设计，后续可替换 PostgreSQL、对象存储、工作流和版权方台账服务。
